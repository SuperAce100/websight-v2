# KTO Training Setup Guide

## Overview

This guide explains how to run KTO (Kahneman-Tversky Optimization) training on UI-TARS-1.5-7B using LLaMA-Factory, starting from an SFT checkpoint.

**Important**: The data is split so that **70% is used for SFT** and **30% is reserved for KTO**. This ensures no overlap between the two training phases.

## Prerequisites

1. **SFT Checkpoint**: You must have completed SFT training first
   - Expected location: `saves/ui-tars-1.5-7b/lora/agentnet`
   - Generated by: `slurm/train_ui_tars_agentnet.slurm`
   - If using a specific checkpoint, use: `saves/ui-tars-1.5-7b/lora/agentnet/checkpoint-XXXX`

2. **Merged AgentNet Data**: The merged agentnet file must exist
   - Expected location: `/hai/scratch/asanshay/websight-v2/agentnet/agentnet_all.jsonl`
   - Generated by: `slurm/prepare_agentnet.slurm` (if not already present)

3. **AgentNet Images**: Screenshot directory must be available
   - Expected location: `/hai/scratch/asanshay/websight-v2/agentnet/images`

4. **KTO Split File**: Created during SFT data preparation
   - Expected location: `data/agentnet_kto_split.jsonl`
   - Generated by: `transform_agentnet_for_training.py` with `--save-kto-split` flag

## Step-by-Step Instructions

### Step 0: Prepare SFT Data (If Not Already Done)

The SFT transformation script now automatically reserves 30% of data for KTO:

```bash
python scripts/agentnet_scripts/transform_agentnet_for_training.py \
  --input /hai/scratch/asanshay/websight-v2/agentnet/agentnet_all.jsonl \
  --output-dir data \
  --base-image-dir /hai/scratch/asanshay/websight-v2/agentnet/images \
  --kto-ratio 0.3 \
  --save-kto-split
```

This will:
- Use 70% of trajectories for SFT (split into train/val/test)
- Reserve 30% for KTO and save to `data/agentnet_kto_split.jsonl`
- Ensure no overlap between SFT and KTO data

### Step 1: Prepare KTO Data

Transform the reserved 30% of AgentNet trajectories into KTO format:

```bash
# Run the preparation script
bash scripts/data_prep/prepare_kto_data.sh
```

This will create `data/agentnet_kto.jsonl` with:
- `messages`: Conversation in ShareGPT format
- `images`: List of image paths
- `kto_tag`: true for task_completed=True, false for task_completed=False

### Step 2: Verify Dataset Registration

The dataset should already be registered in `configs/dataset_info.json` as `agentnet_kto_train`. Verify it exists:

```bash
grep -A 10 "agentnet_kto_train" configs/dataset_info.json
```

### Step 3: Verify SFT Checkpoint

Check that your SFT checkpoint exists:

```bash
ls -la saves/ui-tars-1.5-7b/lora/agentnet/
```

You should see adapter files (e.g., `adapter_config.json`, `adapter_model.bin` or `adapter_model.safetensors`).

If you want to use a specific checkpoint instead of the final one:

```bash
# Edit configs/train_agentnet_kto.yaml
# Change adapter_name_or_path to:
# adapter_name_or_path: saves/ui-tars-1.5-7b/lora/agentnet/checkpoint-XXXX
```

### Step 4: Submit KTO Training Job

Submit the SLURM job:

```bash
sbatch --account=ingrai slurm/train_agentnet_kto.slurm
```

Monitor the job:

```bash
# Check job status
squeue -u $USER

# View logs
tail -f logs/train_agentnet_kto_*.out
```

## Configuration Details

### KTO-Specific Parameters

The configuration file (`configs/train_agentnet_kto.yaml`) includes:

- **stage**: `kto` (not `sft`)
- **pref_beta**: `16.0` - Controls balance between reward and KL penalty
  - Typical range: 8-32
  - Higher values = stronger preference signal
- **pref_loss**: `kto` - KTO loss type
- **adapter_name_or_path**: Points to SFT checkpoint
- **learning_rate**: `2.0e-5` - Lower than SFT (KTO typically uses 1e-5 to 5e-5)

### Training Hyperparameters

- **Batch size**: 2 per device × 4 gradient accumulation = effective batch size 64
- **Epochs**: 1.0 (KTO converges faster than SFT)
- **LoRA**: Same settings as SFT (rank=64, alpha=128, rslora=true)

## Output

After training completes, the KTO adapter will be saved to:

```
saves/ui-tars-1.5-7b/lora/agentnet-kto/
```

## Troubleshooting

### Error: SFT checkpoint not found

Make sure you've run SFT training first:
```bash
sbatch --account=ingrai slurm/train_ui_tars_agentnet.slurm
```

### Error: KTO data file not found

First, ensure the KTO split file exists (created during SFT data preparation):
```bash
ls -la data/agentnet_kto_split.jsonl
```

If the split file doesn't exist, re-run the SFT data preparation with the --save-kto-split flag:
```bash
python scripts/agentnet_scripts/transform_agentnet_for_training.py \
  --input /hai/scratch/asanshay/websight-v2/agentnet/agentnet_all.jsonl \
  --output-dir data \
  --base-image-dir /hai/scratch/asanshay/websight-v2/agentnet/images \
  --kto-ratio 0.3 \
  --save-kto-split
```

Then run the KTO data preparation script:
```bash
bash scripts/data_prep/prepare_kto_data.sh
```

### Error: Images directory missing

Ensure AgentNet images are extracted:
```bash
# Check if images exist
ls /hai/scratch/asanshay/websight-v2/agentnet/images/ | head
```
